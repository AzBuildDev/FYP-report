# 机械臂控制项目约定

- 自建运行、部署、测试和辅助脚本放在 `脚本/`，用中文命名并说明用途。
- LeRobot 源码位于 `上游框架/`，Git 历史位于项目根目录；Python 导入路径为 `上游框架/src`。
- Python 环境、缓存和临时文件分别位于 `运行环境/虚拟环境/`、`运行环境/缓存/`、`运行环境/临时文件/`。
- 模型、日志和标定分别放在 `模型/`、`运行记录/`、`标定备份/`。说明放在 `文档/`，旧实现放在 `历史版本/`。
- 新演示保存在毕业设计项目 `训练数据采集/机械臂控制项目/任务演示/单相机演示_时间/`。保持视频、状态、动作、任务和元数据的对应关系。
- 固定的软件接口名和数据格式保留；普通自建资料用中文命名。
- 修改路径后验证入口、导入、模型加载与保存流程。目录整理不自动发出机械臂动作。
- Python 使用 UTF-8；中文批处理使用 `chcp 65001 >nul` 并给路径加引号。

- 脚本根目录仅保留项目控制台、入口清单和使用说明；单项入口按日常操作、离线实验、检查工具、环境配置、历史工具分类。Python 实现和测试模块放在 `脚本/程序模块/`，项目根为其上两级。
- 新的可见操作加入 `脚本/入口清单.json`；保持内部中文模块的同目录导入，目录整理不启动真实硬件。

- 按用户要求，采集指引和采集相关实现/入口统一放在 `脚本/数据采集/`；共享训练、控制和相机模块仍在 `脚本/程序模块/`。采集模块显式导入共享模块目录，面板与控制台使用同一真实入口，不新增重复壳脚本。
- 开发维护 `文档/开发文档.md`，依次是最新开发进度、以往版本记录、后续优化；每轮开发更新开头并保留历史。结构与数据链路变化同步更新 `文档/项目说明.md` 和 `脚本/数据采集/数据采集指引.md`。
- 新采集失败、放弃和保存异常均保留独立尝试；未确认归档完成不能清除原始帧，封存批次不继续写入。独立验证数据不得参与训练。
- 当前用户要求新开发在 `smolvla-data-collection` 分支同步，不直接推主分支。
- 每轮开发收尾须提交并推送本地代码、核心文档和进展摘要到 `github-smol/smolvla-data-collection`，随后核对本地 HEAD 与远端提交一致；开始工作前检查远端更新，存在分歧时保留双方改动并处理冲突，不强制覆盖。同步失败应明确记录尚未同步的内容与原因。模型、环境、标定、原始视频及原始日志仍留本机。
