# SmolVLA 开发文档

## 一、最新开发进度

更新：2026-10-07。主线任务：桌面单相机观察，SO-101 主从双臂演示，SmolVLA 抓取红色方块并放到固定目标区。

本轮完善采集流程，并把采集指引、录制入口、批次检查、视频恢复和采集自检放到 `脚本/数据采集/`。项目控制台仍是总入口，采集训练面板已经指向新位置。

- 每次尝试生成独立编号，重录不覆盖旧动作备份。成功、失败和操作者放弃均保留原始帧及动作/状态；归档成功后才允许清除上游临时缓冲。
- 录制增加场景、普通/纠偏类型及训练/独立验证用途。用途和任务指令在批次创建后锁定，场景可在下一段前修改。
- 保存前归档，保存后重读视频与表格核对帧数。编码或归档异常会封存批次，禁止在同一批继续写入；重开窗口产生新批次。
- 六关节保留正常同步设置。接入启用前与运行中的电机状态检查，初始姿态差检查、有限数/标定范围检查，以及逐电机停扭矩读回与串口释放。相机过期、黑帧和分辨率变化停止本段。倒计时在从臂启用扭矩前进行。
- 新批次检查核对人工确认、场景、原始帧、动作备份和 parquet 的一致性。封存批次不能进入面板训练；训练脚本与面板均拒绝标记为独立验证的批次。
- 指引安排 3 段试录、30 段训练、另批次 10 段独立验证。用户已确认继续红色方块任务；数量是首轮计划，不是已采集数量或效果保证。

验证：10 项数据保护检查通过；隐藏窗口、模拟双臂配合真实 LeRobot 视频编码完成“归档重录→另次保存重读→注入编码失败→保留数据并封存”的集成验证，后台无控制台输出正常。本轮没有启动真实机械臂，没有新增真实演示。另有 19 项面板、10 项训练来源检查和 4 项控制台检查通过；批处理目标、核心文档链接和全部自建 Python 语法核对通过。完整软件验证摘要见 [采集流程完善报告](项目进展/采集流程完善报告.json)。

当前真实数据仍是 3 段 / 1,114 帧。已有 3,000 步训练基线和整段留出实验；单次用户确认抓取放置成功已记入人工结果，不能推算自主任务成功率。原始过载、停扭矩异常及恢复证据继续保留。最近整理时的只读检查没有检测到设备，不能解释为电机扭矩关闭。

本轮代码按用户要求在新分支 `smolvla-data-collection` 维护。已将本地与 GitHub 同步写入项目约定：每轮验证后提交、推送并核对双方提交一致；开始工作前检查远端更新，保留并处理双方改动。GitHub 只同步代码、说明与脱敏验证摘要；模型、环境、标定、原始演示和日志留在本机。

### 外部建议的取舍

阅读了 [WorkBuddy 优化讨论](https://workbuddy.link/p/ZBHEL74o5ijxURS07QvG8f?ext2=copy_link)。本轮采纳不同位置、朝向和纠偏过程的采集建议，将抓取判定、重试状态机列入后续实验。

该讨论中的“100% 动作完成率”“33% 成功率”不是当前项目已核验统计；170000/200000 等检查点属于历史方案，不能直接当作当前 SmolVLA 的可选模型。当前控制已有实时图像反馈，仍可能在动作窗口内滞后；“方块碰偏导致空抓”需要现场视频和分阶段标签证明。不会把未验证诊断写成实验结论，也不保证增加多少演示后一定提高成功率。

## 三、之后可以优化的方向

优先级从当前可执行步骤开始：

1. **完成新采集与人工审查。** 先检查 3 段试录的视频、动作同步和完整抓放，再执行 30+10 计划。训练与独立验证另批次、另一次采集，避免逐帧随机拆分造成泄漏。
2. **适应更大数据量的训练读取。** 当前训练脚本预载视频，约 1 GB / 1,114 帧。扩充后需改为按段/窗口读取或受限缓存，并验证尾部补齐、帧索引与训练吞吐。不能不估算内存就直接对全量扩充数据训练。
3. **记录定位、夹取、抬起、放置阶段结果。** 先由用户标注视频证据；分别记录“对准后碰偏”“闭合空夹”“抬起滑落”“放置失败”，再判断瓶颈。
4. **抓取判定实验。** 本地部分 Feetech 型号表提供 `Present_Current` 与 `Present_Load`，其他型号可能没有电流寄存器。先确认实际型号、可读性、单位及读取延迟，再采“空夹/夹到/滑落”带人工标签的读数。位置残差和电流均会受摩擦、姿态、堵转影响，不能单阈值冒充可靠成功判定。结合抬起后图像进行对照验证；不把过载状态作为抓取成功。
5. **显式阶段与有限重试。** 仅在判定器经过独立测试后接入重试状态机。定义未知状态、停止条件、最多重试次数与模型动作切换策略，先模拟，再经用户现场授权测试；当前尚未实现自动重试。
6. **末段对准与时效。** 基于桌面相机可见性分析动作窗口滞后；缩短窗口或局部视觉对准必须做离线对照。历史视觉伺服代码可供参考，尚未接入 SmolVLA。夹爪相机双路采集的问题继续单独排查。
7. **检查点与真实评测。** 使用新独立数据比较 SmolVLA 检查点，预先固定评测摆放和次数，用真实完整日志加人工结果统计，并报告未知/故障中止次数。

维护规则：每次开发先更新第一部分的实际状态和验证，再将版本记录加入第二部分；第三部分删去已完成项或明确进度。不得用计划或模拟指标替代真实采集与成功率。
