# 本地部署说明

当前项目根目录为 `D:\FYP\毕业设计项目\机械臂控制项目`，主线使用 SmolVLA 与 SO-101。代码和进展保存在私有仓库 [SmolVLA-SO101-FYP](https://github.com/HDTHDT/SmolVLA-SO101-FYP)。本地开发分支为 `smolvla-development`，同步到该仓库的 `main`；上游原始分支与 Git 历史保留。

## 安装与检查

本机已经配置 Python 3.12.5、LeRobot 0.3.4、PyTorch 2.7.1+cu128、torchvision 0.22.1+cu128 和 RTX 4060 Laptop GPU。重新安装时先提供 Python 3.12 和 Windows Python 启动器，在项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "脚本\环境配置\安装本地环境.ps1"
```

安装脚本使用 `文档/环境依赖.txt`，创建或复用 `运行环境/虚拟环境/`，安装本地 `上游框架/` 及依赖，并检查依赖一致性。仓库不包含本机虚拟环境；新机器需重新安装。当前机器已验证离线推理和训练，新机器仍需运行检查确认。

双击 `脚本/环境配置/打开项目终端.bat`，该终端会配置环境、框架导入、缓存与标定目录。随后运行：

```bat
python -m pip check
python 脚本\程序模块\检查本地环境.py
python 脚本\程序模块\下载预训练模型.py
脚本\历史工具\离线测试.bat
脚本\检查工具\训练评估流程自检.bat
脚本\检查工具\控制流程完整自检.bat
```

模型下载仅在模型缺失时需要联网；指定版本与目录见[模型部署与测试说明](模型部署与测试说明.md)。检查环境和模拟测试不发送真实机械臂命令。权重、原始视频和标定留在本机，复制代码仓库本身不会带上这些文件。

## 采集与实机入口

采集使用 `脚本/数据采集/录制任务演示.bat`，窗口由用户手动开始、停止和保存。训练和评估参数见[训练与独立验证流程](训练与独立验证流程.md)。默认新训练模型另存到时间目录，不覆盖已有实机基线。

当前主臂 USB 序列号为 `5C82108314`，从臂为 `5C82108242`；串口号可能随插口变化。标定文件分别在 `标定备份/robots/so101_follower/` 与 `标定备份/teleoperators/so101_leader/`，文件名对应本机设备 id。硬件连接与标定需在新机器重新核对。

实机基线入口为 `脚本/日常操作/实机抓取测试.bat`，准备检查后等用户按回车才启用扭矩。具体步骤、停止方式和结果记录要求见[实机评测流程](实机评测流程.md)。双路相机问题暂缓，当前训练和测试使用桌面单相机。
