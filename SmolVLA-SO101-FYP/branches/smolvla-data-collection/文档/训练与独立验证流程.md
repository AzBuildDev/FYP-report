# 训练与独立验证

划分时以完整演示段为单位，不把同一段相邻帧分到训练和验证两侧。当前流程要求 20 FPS、六个关节且动作与状态顺序一致，避免训练时间步与 20 Hz 控制不同。归一化均值、标准差及视频预载只用所选训练段。新模型会保存 `训练数据来源.json`，包含训练段、内容指纹和对应检查点的 SHA-256。

以下命令在项目终端执行。入口的默认数据批次仍为当前三段真实演示，编号从 0 开始。

```bat
脚本\离线实验\微调预训练模型.bat --episodes 0 1 --steps 1000 --output-dir "模型\整段留出实验模型" --dry-run
脚本\离线实验\微调预训练模型.bat --episodes 0 1 --steps 1000 --output-dir "模型\整段留出实验模型"
脚本\离线实验\评估微调模型.bat --model-dir "模型\整段留出实验模型" --episodes 2 --require-held-out
```

第一行只检查训练计划。训练输出目录必须为空；已有模型不会被覆盖。不指定输出目录时使用 `模型/红色方块微调_时间/`。新训练模型不会自动替换实机入口所用的基线模型。每次训练和评估的结果分别保存在 `运行记录/模型微调结果_时间.json` 和 `运行记录/模型离线评估_时间.json`，原有基线报告保留。

评估支持 `--dataset-root "完整批次目录"`、`--model-dir`、`--episodes`、`--samples-per-episode`、`--check-only` 和 `--output-report`。`--check-only` 只检查数据与来源，不推理。`--require-held-out` 要求检查点与来源记录匹配且未发现训练内容重叠；同一批次同段号、相同动作/状态内容或相同视频都会判为重叠。复制目录或重新编号不会把相同内容变成留出数据。

现有三段、3000 步基线模型是在这次来源记录功能加入前训练的。历史训练记录确认三段均已参与训练；对这个模型重新划分三段不能产生留出验证。缺少来源文件的模型在新评估中标为 `training_provenance_unknown`，拒绝通过 `--require-held-out`。需要从基础模型用训练段重新训练实验模型。

同批次留出只检查未参与该次训练的完整段，仍可能有相同的方块位置、光照和动作习惯，不能代表新场景泛化。内容指纹可发现完整复制，不保证识别裁剪、重编码或修改过的数据；应保留原始采集批次和人工划分记录。后续优先使用另一次独立采集、不同物体位置的批次作为验证。动作误差和模型输出正常也不等于实机抓取成功。

`训练评估流程自检.bat` 使用临时软件测试素材验证划分、统计和来源绑定，不会把测试素材写入真实演示目录，也不连接硬件。
