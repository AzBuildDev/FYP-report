# SmolVLA 与 SO-101 机械臂毕业设计

用桌面单相机与主从双臂采集演示，微调 SmolVLA，实现红色方块抓取与放置。当前已完成采集、3000 步基线微调、单独模型的整段留出动作评估和异步控制模拟验证，实机抓取成功率尚未验证。

目前用户已完成断电检查并重新上电，随后只读复查无故障、从臂扭矩均关闭；后续完整日志的最后一条正常退出。当前连接检查没有检测到机械臂设备。本轮仅整理和验证软件，不启用硬件。用户此前确认过一次成功抓取并放置，后续尝试结果仍待人工标记，不据单次结果估计成功率。

历史过载、停扭矩读回异常及恢复过程均保留：[运行记录统合](文档/项目进展/项目运行记录统合摘要.json)、[过载与复测记录](文档/项目进展/实机过载排查记录.md)。脚本已集中到一个中文总入口，原始快照和路径映射可追溯。

## 本地目录

本仓库对应 `毕业设计项目/机械臂控制项目/`。同一毕业设计的另外两部分为其同级 `训练数据采集/` 和 `毕业论文资料/`。新录制的演示保存在 `../训练数据采集/机械臂控制项目/任务演示/`。

`脚本/` 放中文操作入口；`上游框架/` 保留 LeRobot 源码；`文档/` 放部署说明和进展。运行环境、模型权重、原始视频、标定和原始运行日志留在本机，进展报告放在 `文档/项目进展/`。

## 操作入口

统一入口：[脚本/项目控制台.bat](脚本/项目控制台.bat)。日常操作、离线实验、检查工具和历史工具分开；底部可打开进展、日志和训练数据。

脚本根目录只保留总入口、入口清单和操作说明。需要直接调用时，使用分类目录中的批处理。采集指引与实现位于 `脚本/数据采集/`，共享实现位于 `脚本/程序模块/`。完整步骤见 [脚本使用说明](脚本/使用说明.md)。

| 位置 | 用途 |
|---|---|
| `脚本/数据采集/` | 采集指引、录制、归档、批次检查、恢复和自检 |
| `脚本/日常操作/` | 采集训练面板、同步、相机、抓取、真实结果 |
| `脚本/离线实验/` | 数据检查、训练、评估、对比和模型验证 |
| `脚本/检查工具/` | 只读设备检查与软件自检 |
| `脚本/环境配置/` | 环境安装与配置 |
| `脚本/历史工具/` | 旧视觉方案和兼容入口 |
| `脚本/程序模块/` | Python 实现及测试 |
