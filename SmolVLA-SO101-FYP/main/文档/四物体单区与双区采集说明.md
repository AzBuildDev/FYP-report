# 四物体单区与双区采集支持

2026-10-30 说明：以下为 10 月 24 日四物体方案的历史实现记录。当前录制窗口已按操作者要求简化为仅选择 RC/BC，以下阶段、布局及会话表单不再出现在录制窗口；旧数据的标签读取、检查与训练限制继续保留。当前录制操作见 [启动与采集操作指南](启动与采集操作指南.md)。

更新：2026-10-24。本轮将采集执行手册中的任务目录和布局规则接入软件；手册是计划依据，不能视为已经完成的采集或实测结果。

## 已实现

- 四种对象：RC 红方块、BC 蓝方块、GCy 绿圆柱、RCy 红圆柱。自动生成完整英文指令，明确区分 red cube 和 red cylinder。
- I-A 单物体到原区域，I-B 四物体同场到原区域，II 四物体同场到 A/B。分别为 200、200、400 条空白配额，共 train 640、dev 160。
- I-B 和 II 沿用同一 R01–R10、K1–K5 布局。R01–R08 为 train，R09–R10 为 dev；I-A 每位置序号 1–8 为 train、9–10 为 dev。
- 录制窗口在段间允许更换任务；录制中和待保存时锁定选择。逐帧 task 写入 LeRobot，由 task_index 对应真实英文文字。
- 每个已保存的计划段另写 `meta/collection_labels/episode_000000.json`，记录阶段、场景、布局、对象、区域、起点、split、会话、操作者和布局/硬件配置版本。动作备份头也记录当段标签。
- 数据检查核对标签、规范文字、逐帧 task、配额身份与完整性；缺失或错误标签使检查失败。训练和训练计划拒绝所选 dev 段。
- 训练来源保存逐段标签。独立验证除内容哈希外，还检查同配置版本下的 scene_group_id，防止同布局不同指令或跨 I-B/II 被误算独立验证。

## 操作

1. 项目控制台 → 离线实验 → “导出四物体采集计划”。CSV 写入新的 `运行记录/四物体采集计划_时间.csv`。这是待采集清单，质量和文件关联栏留空；不意味着已完成。
2. 打开“录制任务演示”，选择 I-A、I-B 或 II，选择物体、目的地、轮次；I-A 指定起点，I-B/II 指定 K 布局。窗口显示完整指令、split 和 P1–P5 摆放。
3. 填写会话、操作者、布局/硬件配置版本。配置版本应对应实际保存的桌面锚点、区域位置、相机和标定记录；同一布置在不同批次和 I-B/II 中沿用同一身份，不要为绕过组检查改名。
4. 人工核对摆放、物体直立、区域为空、两臂 home，再自行开启相机和开始录制。每段只做一个抓放。停止后只保存成功段，失败则丢弃重录。
5. 每次保存后自行选择下一项；软件不自动移动机器人、切换计划项或执行复位。同一批不能在“自由任务”和计划模式之间切换；需要时重开录制窗口创建新批次。
6. 训练面板中先检查批次，在数据检查报告 `collection_labels` 核对各 episode 的 split，再显式选择 train 编号；默认全选包含 dev 时训练计划会拒绝。开发段用于离线评估，不参与梯度更新。

界面“轮次/序号”在 I-A 表示每个位置的第几条，在 I-B/II 表示 R 轮次。混合场景的目标起点由布局计算，忽略 I-A 起点选择框。同一计划项在一个批次中不能重复保存；不同批次仍须按清单人工核对，不自动合并重复配额。

保存按钮表示操作者确认该段成功，程序不会从视频自动判断抓取、入区或稳定。失败录像的独立台账、全批次配额汇总、多批次联合训练与任务均衡采样、语音任务目录接入、实机模型效果评估仍需继续开发/验证。本轮不将这些功能描述为已完成。

## 旧数据

原红方块 50 段及原 40/10 划分保持原状，不自动写入新标签、挪动开发段或重命名任务。仅在逐段核对原场景、起点、质量、文本及原始划分后，才能抵扣 I-A 对应配额；不能抵扣四物体同场或 A/B 的新任务。

自由任务保留手输英文方式，现可在段间切换文字，但没有计划标签和布局分组保证。未经记录的布局/角度不能据此补填。旧批次的内容哈希与留出检查继续适用。

