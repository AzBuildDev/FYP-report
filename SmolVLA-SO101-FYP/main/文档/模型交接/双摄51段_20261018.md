## 当时的离线比较结果

| 候选 | 训练段 | 验证段 | 标准化动作 MAE（越低越好） |
|---|---|---|---:|
| 3,000 步，离线 MAE 较低 | 0–45，24,959 帧 | 46–50，2,467 帧 | **0.169833** |
| 10,000 步 | 相同 | 相同 | 0.174489 |

每个模型在相同的 5 段验证数据上各抽取 5 个位置，共 25 个动作片段；seed=42、batch size=4。训练从同一基础模型起步，冻结视觉编码器，仅训练配置指定的专家与状态投影。3,000 步误差比 10,000 步低约 2.7%。两组训练均已完成；10,000 步不是在 3,000 步上断点续训。

数据格式 v2.1；20 FPS；`observation.images.front` 与 `observation.images.wrist` 均为 640×480；动作和状态均为六关节，SO101 归一化位置而非角度。

## 历史实验复现步骤

1. 拉取本发布 tag 的代码，按[本地部署说明](../本地部署说明.md)配置 Python 3.10、兼容 CUDA/PyTorch 和仓库内 LeRobot 0.3.4。实际依赖版本随交接包保存。不要提交虚拟环境或沿用另一台电脑的 Python 路径。
2. 从 Release 下载附件，核对 `SHA256SUMS.txt`。Windows 可用 `Get-FileHash -Algorithm SHA256 文件名.zip`。
3. 模型包解压到仓库 `模型/` 下，形成 `模型/smolvla-so101-3000/交接清单.json`；数据包解压到自行选择的数据目录，顶层为 `双相机演示_20261017_174249_955526/`，保持原有子目录不变。
4. 在已配置好的项目终端执行：

```powershell
python "脚本/程序模块/配置交接模型.py" --package-root "模型/smolvla-so101-3000"
```

工具逐文件验证 SHA-256，再把模型配置中的处理器路径更新为本机绝对路径，保留 `config.json.发布原件`。原始训练数据绝对路径用于追溯，不应改写来源文件或指纹。

5. 面板加载模型时，选择 **`模型/smolvla-so101-3000/模型/`**，不是包的顶层目录。先对本机数据重新检查，再验证模型加载和离线推理。CLI 示例（在项目终端中将数据路径替换为本机解压位置）：

```powershell
python "脚本/程序模块/评估微调模型.py" --dataset-root "本机完整数据目录" --model-dir "模型/smolvla-so101-3000/模型" --episodes 46 47 48 49 50 --require-held-out --samples-per-episode 5 --seed 42
```

命令行直接运行 Python 时，应按[本地部署说明](../本地部署说明.md)设置 `PYTHONPATH` 为仓库 `上游框架/src`；Windows 项目终端会自动设置。
