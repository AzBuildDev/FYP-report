# 语音指挥到动作执行

2026-11-05 诊断更正与联网验收：旧通用地址返回 AccessDenied.Unpurchased，不能据此认定本账号未开通百炼或模型。按 API Key 页面改为业务空间专属 Base URL 后，qwen3-asr-flash 和 qwen-plus 均真实调用成功；合成音频被正确转写为“拿起红色的方块，放到目标区域。”，自然表达“请把红色方块移动到目标区”经实际语义链路输出 RC。专属地址已保存到本机配置，密钥未更改，未发送机械臂动作。验收记录：运行记录/百炼专属地址验收_20261105.json。以后应从 API Key 页面复制 OpenAI 兼容 Base URL，优先排除密钥与业务空间地址不匹配；不要只凭 HTTP 403 推断需要重新开通服务。

入口仍是“启动模型推理”，重新打开窗口可见语音指挥区域。没有新增自动开机或自动连接机械臂的后台监听。

1. 重新打开推理窗口，选择“百炼API”。“API设置”里的 Base URL 应复制自该 API Key 页面 OpenAI 图标旁的按量付费地址（以 /compatible-mode/v1 结尾），不要使用 Anthropic 地址。当前本机已保存正确的北京业务空间专属地址；ASR 模型为 qwen3-asr-flash，语义模型为 qwen-plus。保存后点击“准备语音”。API 模式不加载本地 Whisper 或 Qwen。本地离线备用可选择“本地Whisper”。
语义模型默认是 `qwen-plus`，使用同一业务空间的密钥和专属 Base URL；当前 ASR 与语义模型均已联网验收成功。明确口令和常见自然表达由本地解析直接处理，其他表达才调用云端语义模型。
2. 选择 zh（中文）或 en（英文），点击“说话并执行（5秒）”。看到“开始录音”后，可以说固定口令，也可以用自然表达，例如“帮我把那个红色的拿起来”“接下来抓蓝色的”“把目标换成红色”。明确短口令本地直接解析；其他表达先由百炼 ASR 转写，再由“语义模型”归一为 RC/BC/停止/拒绝。目标区固定指本轮演示的区域。百炼模式只在显式录音后上传该段音频和转写文本，由服务商按其规则计费，不自动上传历史录音；识别效果与响应耗时仍需实际联网和真人麦克风验收。
3. 未启动推理时，有效语音目标直接使用当前选定的具体检查点启动推理，无需再点击“启动推理”。窗口会恢复上次使用且路径校验通过的模型、演示和处理器；如果从未使用过模型，需先选择具体检查点。模型或数据失效时不启动，并在语音状态栏说明原因。已运行时，识别通过后提交现有切换请求、清空旧动作，不重新加载动作模型。仅准备语音、无效识别、过期结果以及停止指令不会启动推理。
4. 窗口显示当前目标，点击“切换为RC/BC”直接反转红蓝目标，无需下拉选择。无论是否检测到夹持，收到有效目标请求后都在下一控制节拍切换，清空旧动作并丢弃旧任务的在途推理结果。当前不再等待放置确认。
5. 可以说“停止”请求停止，但需经过录音和识别，有延迟；直接停止仍使用窗口停止按钮。

实机语音入口对明确口令直接做有限语法解析；自然表达才调用百炼语义模型。语义模型使用受限 JSON，只能输出 RC、BC、停止或拒绝，不能生成关节动作；置信度不足、颜色冲突、其他物体、其他区域、含糊、多目标、否定或超出语法范围的请求不执行。繁简字形统一，但不会猜测“翻快”等同音错字，也不猜颜色。录音后若用户手动改目标、停止、关闭或启动另一轮，旧语音结果不再应用。语音不能确认物体实际存在；操作者仍需根据双摄预览确认场景。

语音不会调用旧的合成场景 dry-run 来冒充真实场景验证，也不会使用旧文档中绑定的 30k 动作模型；动作始终由窗口当前选择并实际加载的模型执行。初次启动来源、识别文本和目标写入本轮窗口日志的“启动请求”，运行中的切换仍写入 task_switch。没有更改 SmolVLA 权重、训练方法、控制限位或相机超时保护。

## 模型和环境

- 源码来自 GitHub `HDTHDT/SmolVLA-SO101-FYP` 的 `60d34f0856c71e135c4c537c397a20fc11dd997d`；本地新增桥接控件与实机分发，不覆盖已有未提交改动。
- 本地备用 Whisper 权重放在 `模型/语音指令/`，固定 revision 和 SHA256 来自 `文档/语音模型附件清单.json`。`准备语音桥接模型.py` 支持续传和逐项校验，镜像仅负责传输。Qwen 权重仍保留供历史离线实验使用，当前实机语音入口不加载它。
- 麦克风使用系统默认输入，安装 `sounddevice==0.5.3`。只在点击录音按钮后录制；默认不监听。当前枚举到 `1080P USB Camera-Audio`，实际收音质量需真人试验。
- 录音 WAV 和识别日志保存在 `运行记录/语音录音_*.wav`、`运行记录/语音指令_*.jsonl`；动作日志中的 `task_switch` 同时记录来源和转写内容。
- API 配置在 `运行环境/私密配置/语音API.json`，该文件不含密钥。密钥在同目录的 `语音API密钥.dpapi`，通过 Windows 当前用户 DPAPI 加密，换电脑/用户后重新填写；整个运行环境目录已被 Git 忽略。也支持 `DASHSCOPE_API_KEY` 环境变量，优先于本机保存值；不要把密钥发到聊天、写入源码或训练交接包。
- API 只使用百炼官方 HTTPS 域名，不跟随重定向；连接/读取超时为 5/25 秒，不自动重试。401、403、429 和网络失败会提示原因，不能因 API 失败切换目标，也不会自动转回低质量本地识别。API Key 不写入日志，HTTP 错误不回显原始响应或请求头。
- 本地模式只从本机加载 Whisper，不上传录音。所有模式只在点击后录音；如果识别失败或超时，丢弃结果，不提交新目标。

## 验证边界

离线自检覆盖语音/语义到 RC/BC、否定与歧义拒绝、窗口分发、旧结果过期、持物状态立即切换和旧动作丢弃。合成语音测试只证明软件链路，不代替真人麦克风识别和实机抓放验收。当前“说话并执行”的有效目标会启动实际推理。软件验证使用替代子进程测试启动、重复结果拦截、失败提示和运行中切换；真人测试前先核对窗口里的具体模型、双摄与机械臂工作区域。
