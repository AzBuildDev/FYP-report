# 新200段训练方法与论文核查（2026-11-02）

本次只读检查训练方法与论文，不修改正在运行的服务器训练，不连接机械臂。按操作者说明，以演示内容及任务标签正确为讨论前提。

## 已确认的本机实现

- 当前实际训练器是 AutoDL 包的 `脚本/加速模块/新200段训练.py`；已与服务器核对 SHA256。
- 200段划分160训练、40验证，两者红蓝分别80/80及20/20。
- batch32，每批红16蓝16；分别随机抽取演示及完整50帧动作窗口，再对整个样本列表打乱，图像、关节、任务、动作保持绑定。
- 任务文字进入模型语言分支；RC/BC映射一致，红蓝分词不同，未被48 token上限截断。
- RGB视频解码，不进行灰度转换或颜色抖动；图像按配置缩放补边。
- 冻结视觉语言骨干，训练动作专家和状态投影。配置 `train_expert_only=true`、`freeze_vision_encoder=true`。
- 模型训练是条件流匹配：噪声和动作构成中间状态，对目标速度场计算MSE。不是普通动作均值回归，也不是红蓝分类训练。
- 当前训练率峰值1e-4，warmup500，按30K跨度余弦下降至2.5e-6，之后维持下限；batch32。更长训练在当前计划中意味着继续最低学习率更新，不等于从头采用更长衰减计划。
- 验证为800次固定预测，指标为整段关节动作的标准化MAE，按红蓝平均后选best_val。明确记录 `task_success_evaluated=false`。未评估目标选择、同场景换指令、实际抓取成功率。

## 直接阅读的论文与支持范围

1. SmolVLA (2025), https://arxiv.org/html/2506.01844v1
   - §3及§4.3：多图像、语言、状态条件的流匹配动作专家；冻结VLM，只训练动作专家。前16层VLM、50步动作块、10步流匹配推理与本项目相符。
   - §4.3：仿真微调100K、batch64，实机微调200K；作者同时表示较少步数也可获得较好表现。不是本项目必须训练200K的证据。
   - §4.1：分拣任务指令是将红块放右盒、蓝块放左盒，两种颜色交换位置。它不是与本项目完全相同的“只选红或只选蓝到同一目标区”实验。
   - Figure5：该实验分拣指标同步70、异步50；不能把这个差异直接归因于本项目，但说明执行策略需要单独对照，速度快不保证成功率相同。
2. CLIPort (2021), https://arxiv.org/html/2109.12098
   - §3.2：语言条件抓放，使用抓取/放置位置的交叉熵监督；多任务先采任务再采样本。
   - Appendix A.4：指定颜色方块放指定颜色碗，场景含随机颜色干扰物；支持颜色指令控制抓取在方法上可行。
   - 其动作表示和监督不同于SmolVLA，不能直接套用其损失或200K/600K步数。
3. Causal Confusion in Imitation Learning (2019), https://arxiv.org/html/1905.11979
   - 摘要及§1：模仿策略可能学到与动作相关、但非任务真正原因的线索；低离线误差不保证闭环表现。
   - 支持把位置/状态捷径列为待检验假设；没有证明本项目就是该问题。
4. BC-Z (2022), https://arxiv.org/html/2202.02005
   - §4及§5.2：任务条件策略，以及人在机器人偏离时介入提供正确动作，缓解分布偏移。
   - 支持纠错演示方向；不能据此断言SmolVLA必须采用其辅助损失或负样本比例。

## 判断与下一步

没有发现足以确认“训练代码错误”的证据。冻结骨干、使用流匹配、不增加颜色分类损失均不能单独当作错误。

已证实的不足是评估目标：动作MAE不能回答是否根据指令正确选色。假设包括指令影响不足、位置/状态捷径、训练步数或学习率计划不充分，以及异步执行导致的定位偏差。上述假设尚未通过消融确认。

负样本需区分：干扰物已存在；错抓轨迹如果仍以成功动作监督送入现有损失，会教模型模仿错误；不匹配语言/动作的对比负样本需要另行设计损失；偏离后恢复的正确动作属于纠错演示。没有找到可直接用于本项目的通用负样本比例。

优先固定录制画面、关节状态及初始噪声，只更换RC/BC，对照不同检查点的接近轨迹及正确/错误条件下的动作误差。分析接近/下夹阶段，不用整段MAE代替选色指标。随后以相同摆放进行RC、BC闭环对照，再决定是否开展独立的配对采样、阶段加权或更长学习率计划实验。不得据此直接修改现有续训任务。

若语言对照能分离轨迹而实机下夹仍偏右，优先检查相机/起始状态差异和动作执行；若对照难以分离，再验证条件学习并开展训练消融。
