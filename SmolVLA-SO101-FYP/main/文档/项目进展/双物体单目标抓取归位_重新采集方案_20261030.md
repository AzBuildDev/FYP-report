# 双物体、单目标抓取与归位：重新采集方案

## 用户目标与本轮纠正

用户明确说明：稍早测试过红蓝模型，后来切回旧单红模型只是检查旧模型是否正常。不能把最近两次旧模型日志当作用户误选模型的证据。用户认为旧单红与后续双物体的摆放位置不一致，计划重新录制。

当前目标是：红、蓝两个同形方块同时在场；启动时指定抓红或抓蓝；只抓指定的一个，放入同一目标区域；机械臂回到统一 home 姿态，结束本次任务。另一块不动。后续才扩展到连续下发指令、停止、单独归位等交互。

## 官方例子与本项目的区别

官方 `lerobot/svla_so100_sorting` 中的任务是一段连续演示先后处理两个方块，分别进入两个盒子。已取得第 0 段两路原始视频、原任务文字，确认该段约 32.07 秒。示例位于 `D:\FYP\官方参考数据\SmolVLA_SO100颜色分拣`，来源、版本、镜像及 SHA256 校验见该目录说明。

我们的一段演示只处理一个指定目标，两种指令都使用同一个目标区域。无需模仿官方在一段里抓两块或设置两个目标盒。

## 位置不一致的判断边界

物体起点变化本身是正常且有益的训练变化，不能据此判定训练失败。需要核对：相机安装/画面、机械臂标定、关节数据语义、初始姿态、目标区定义是否一致，以及每个位置是否同时有抓红/抓蓝、颜色互换的演示。若旧单红和双物体来自明显不同的拍摄或执行条件，混合后会增加学习难度；尚无对照实验能证明这是此次失败的唯一原因。

已有某次红蓝运行的首个控制姿态与录制首帧差别显著，但无法仅凭该日志断定它就是用户刚才所指的失败测试。保留为排查线索。

## 新一批的录制规则

1. 固定并记录相机、标定、桌面、统一目标区和可重复的 home 姿态。相机位置变化后重新核对；home 不应只靠肉眼判断。
2. 每段开始时红蓝都在场，目标区清空，机械臂在 home，夹爪状态一致。
3. 开始录制，按本段指令接近对应方块、夹住、抬起、放到统一目标区、松爪、离开物体、回 home；回稳后结束录制。
4. 另一块保持原位；手动复位、调整方块、纠错重抓过程不混进成功演示。出现错误时将本段标为待复核或废片。
5. 同一布局分别录 RC 与 BC；再互换两个方块的颜色位置，分别录 RC 与 BC，防止颜色与固定位置绑定。
6. 每条记录真实布局、目标颜色、成功与否及是否已归位；新批次单独保存。旧数据保留供对照，首轮新实验优先单独使用统一规则的新批次。

建议首批完整设计：5 组双物体布局 × 2 种颜色互换 × 2 个指令 × 每格 5 条 = 100 条，抓红 50、抓蓝 50。5 组布局指两块方块的成对位置，而不是两块同时放在一个点。这是本项目的建议，不是官方对指令选色任务的规定。是否增加样本依据实际效果，不把 100 条作为成功保证。

若采用“含归位”的新任务文字，需要在开始新采集前同时明确录制标签和后续推理映射，避免训练与推理指令不一致。可选规范为：

- RC：`Pick up the red cube, place it in the target area, and return to the home position.`
- BC：`Pick up the blue cube, place it in the target area, and return to the home position.`

当前正式代码仍保留既有任务文字，未因本文自动修改或启动录制。不能给不含归位动作的旧演示直接改成上述标签。

## 归位、完成与后续指令

演示包含归位可以教模型完成回程，但当前 SmolVLA 输出关节动作块，不直接输出可靠的“任务成功/已完成”标记。当前推理窗口持续运行至点击停止，也不会因写入“归位”文字就自动进入等待。

需要程序管理“等待指令 → 执行抓取和回程 → 确认完成 → 等待下一条指令”。完成判定需区分：初始已在 home，与执行任务后重新回 home；还要核对目标放置，不能仅靠固定运行秒数或一次 home 读数认定成功。

停止应由控制程序直接响应，无需等待模型理解“停止”。单独归位可以使用验证过的回位动作/轨迹，或另行采集归位任务；不应假定抓红/抓蓝两类演示足以学会任意状态下的单独归位。

连续抓第二个方块时，目标区已有第一个方块。后续应补充“目标区已有物体”的演示或采用可容纳多块的目标区域，并定义是否要求相同落点；当前第一阶段统一以目标区空置开始。
