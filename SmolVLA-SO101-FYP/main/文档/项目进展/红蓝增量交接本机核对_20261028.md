## 软件与手册差异

| 项目 | 本机状态 | 对后续的影响 |
| --- | --- | --- |
| 录制入口 | `脚本/日常操作/录制任务演示.bat` 存在 | 可以继续人工采集 |
| 切换颜色 | 自由任务模式段间可切 RC/BC，自动更新完整英文任务；录制中和待保存时锁定 | 保存或丢弃后即可切色，不必每次关窗重开 |
| 两物体场景信息 | 自由任务模式不自动保存双物体位置、布局、split 等完整台账 | 采集时另记批次、段号、颜色、目标位置、场景、质量和训练/开发归属 |
| 录制时长 | 最长 30 秒，少于 50 帧即 2.5 秒不能保存 | 与手册一致 |
| 多批次联合训练 | 自建面板及微调脚本一次只接收一个 dataset-root；未找到本项目已配置的数据合并入口 | 需要先准备兼容合并或多批读取，不能直接拼文件夹 |
| 初始化权重 | 微调脚本固定加载基础预训练模型配置和权重 | 不能直接宣称从成功红色模型续训；续训前需实现并核对兼容性 |
| 任务采样 | 现入口在所选完整 episode 之间均匀抽样 | 没有旧版固定 20/40/40 比例；也未记录每条任务实际曝光计数 |
| 实机文字任务 | 当前实机抓取脚本 TASK 固定为红色；推理窗口调用该脚本 | 红蓝文字切换验收需要先增加任务选择和传递 |
| 语音 | 未发现本项目自建语音识别到规范红蓝指令的实现 | 先做文字验收，再接语音映射 |
