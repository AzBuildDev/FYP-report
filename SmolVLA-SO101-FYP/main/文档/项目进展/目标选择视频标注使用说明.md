# 目标选择视频标注（自动保存版，2026-11-07）

入口：项目控制台 → 离线实验 → 标注目标选择视频，或双击 `脚本/离线实验/标注目标选择视频.bat`。

## 切换数据集

右上角“切换数据集…”可选择数据集文件夹；“输入数据集路径…”可直接粘贴路径。支持含meta、data、videos的根目录，也支持它下面的相机视频文件夹（甚至视频文件路径），自动向上找到根目录并同时读取front/wrist。

本次新增支持的实际目录：

`D:/FYP/训练数据采集/机械臂控制项目/任务演示/双相机演示_20261030_200119_173830/videos/chunk-000/observation.images.front`

该数据集共100段。标注按数据指纹分别保存；切换前自动保存位置，切回恢复本数据集的标记及游标。再次选择当前数据集会复用当前窗口，不产生第二个写锁。无效路径加载失败时继续保留原数据集。

## 标记与保存

每段保持一个“首次接触目标”事件：夹爪第一次明确接触本段RC/BC目标方块的那一帧。不要求尚未合爪，不等夹紧或提起。此次改动只调整数据集切换及保存流程，没有改写已有标记定义和帧号。

1. 空格播放/暂停；拖动进度条或用←/→逐帧定位，可调播放速度或输入帧号。
2. 按 **1** 或点标记按钮，立即自动保存。重按1覆盖旧位置。
3. PgUp/PgDn切前后段；无需核对勾选，也无需点击确认。数据集原RC/BC标签只显示，不修改。
4. 标错可选中表格行按Delete；删除仅影响标记，原视频保留。看不清可先跳过，列表显示未标注。
5. 完成一部分或全部后，点“导出已标注数据…”。所有已有有效标记的段直接导出，未标注段不导出。Ctrl+S可手动保存；关闭也自动保存。

原“已核对”勾选、“确认本段”和“不适用”按钮已移除。列表只区分已标注/未标注。原200段已确认数据以及旧版已打标草稿都可直接使用，不要求重做。旧版曾明确跳过的记录仍保留，在重新按1标记前不导出。

## 保存位置和兼容

自动保存：`运行记录/目标选择时间标注/首次接触_数据指纹前12位.json`，保留上一版`.备份.json`。导出另存`_训练导出.json`，源数据目录只读。

旧三标记文件有永久备份，只继承同义的首次接触，其余旧信息保留，不重新解释帧号。标记时绑定视频SHA256，导出时检查视频是否改变；旧记录如已有哈希也继续验证。

视频号和帧号从0开始。列表第1段对应视频000000，不直接套用原录制JSON从1开始的编号。

## 训练用途

仍是阶段采样实验：增加接触前输入的抽样机会，同时保留全段窗口训练。输入是该帧双摄图像、关节状态及RC/BC指令，监督为未来50步真实动作，可以跨过接触点，不裁掉放置归位。

标注不构成错误指令惩罚，也不保证改善颜色选择。完整训练器尚未接入，标注/导出不会启动训练或机械臂。
