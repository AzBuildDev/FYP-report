# 实机结果记录

双击 `脚本/日常操作/实机结果记录.bat`。这个窗口只读取日志和保存人工结果，不连接或启动机械臂，也不会根据程序运行完毕自动标记成功。

1. 点击“刷新测试列表”，选择已经有完整结束记录的日志。
2. 核对任务、模型身份、停止原因、动作次数和场景。填写实际方块位置或场景名称、记录者及备注。
3. 按观察选择成功抓取并放置、抓取失败、放置失败、人工中断、程序异常或开始前取消；默认不选择成功。
4. 勾选“本人观察了这次真实硬件测试”，点击“保存 / 修正人工结果”。修正保留之前的历史，同一日志仍只算一次。
5. 点击“导出评测汇总”，将 JSON 和可用 Excel 打开的 CSV 保存到 `运行记录/实机评测/`。原始日志保留，人工结果存于 `人工结果标记.json`。

新运行日志记录检查点内容指纹、场景和控制模式。可用 `实机抓取测试.bat --scene "方块偏左"` 指定场景；该入口仍由用户手动按回车开始动作。记录窗口不启动这个入口。

## 统计规则

- 按场景、模型检查点、控制模式和任务分别统计。程序开始且实际发送过控制动作才计为一次尝试。
- 成功率分母包含抓取失败、放置失败、人工中断和程序异常的尝试；零动作及开始前取消单列，不计入分母。
- 有待标记的尝试时不显示该组成功率。汇总只覆盖完整可关联日志，未确认旧日志、未结束或损坏的日志另列；不能把它当作所有历史运行的完整统计。
- 没有模型身份记录的旧日志需本人确认真实观察后才能登记，逐次列出，不与已知检查点合并比较。
- 模拟、离线以及其他非实机来源的日志不能登记为真实结果。自检全部使用临时测试素材，测试统计不进入项目真实评测。
- 人工标记绑定日志内容指纹。日志被修改或缺失后原标记失去关联，汇总会提示；复制同一日志不重复计数。
- 日志有程序或资源清理异常时，不接受“成功抓取并放置”作为完整成功；请标记程序异常，并在备注说明实际物体是否放置完成。

活动发送频率来自控制日志，不能替代任务成功率，也不表示机械臂物理位置已按同样频率跟随。停止原因和资源清理记录用于定位程序问题，缺少停止请求时间时不能据此计算扭矩释放延迟。

不打开窗口导出汇总可运行 `脚本/日常操作/实机结果记录.bat --summary-only`。`脚本/检查工具/实机评测记录自检.bat` 检查结果保存、修订、日志去重、模拟排除、统计和窗口操作，不访问真实硬件。
