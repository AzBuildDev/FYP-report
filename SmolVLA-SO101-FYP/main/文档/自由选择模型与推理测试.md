# 自由选择模型与推理测试

2026-10-18 起，实机抓取测试和模型启动离线验证不再固定选择旧模型。双击原来的批处理即可打开选择窗口，不需要改 Python 源码、改模型配置或移动到朋友电脑使用的盘符。中文目录可以保留。

2026-10-19 新五位置实验已解压到 `模型/双摄五位置_20261019_bs16_30000/`，包含 8 个 checkpoint。原约 9.27 GiB 训练 ZIP 中的 65 个模型相关文件已与本机解压副本逐一核对大小和 CRC；去除重复模型归档后，其余原始内容保存为 `模型/外部训练模型/五位置训练源码与实验记录_20261019.zip`。所有解压模型保留，原大 ZIP 已删除。模型、数据与去重归档均不进入 Git，详见 [清理说明](项目进展/仓库清理说明_20261019.md)。

## 选择本次模型

双击 `脚本/日常操作/启动模型推理.bat` 打开实机推理窗口。打开窗口本身不会连接设备；点击“启动推理”才加载模型、检查设备并开始运动。原来的 `实机抓取测试.bat` 无参数双击也打开同一窗口。

1. 在“模型实验目录”下拉框选择训练实验，再在“Checkpoint”下拉框选择 `best_val`、`last` 或具体训练步数（例如 `step_030000`）。窗口下面会显示最终的具体模型目录；这个目录必须至少包含 `config.json`、`model.safetensors`、`dataset_stats.json`。
2. 旧模型仍可加载：`模型/双摄模型_3000步与10000步/` 会作为实验目录，下面选择 `3000步模型/` 或 `10000步模型/`。两者实测只能大致对准物体，无法夹住并完成抓取，仅保留历史复现用途。不要选择没有完整权重的外层目录，也不要把 `.zip` 文件路径填入模型目录。
3. 选择模型后，程序按训练来源中的批次名寻找本机演示。最新五位置模型应显示项目同级的 `训练数据采集/机械臂控制项目/任务演示/双相机演示_20261019_100106_674366/`；旧模型仍应匹配其各自训练批次。没有找到就浏览选择该目录，不能只选里面的 `data` 或 `videos`。
4. “视觉语言处理器目录”通常留空。程序优先寻找模型目录内或模型包内的 `视觉语言处理器/`，随后检查原配置和项目的 `模型/视觉语言处理器/`。找不到时手动选择配套处理器。
5. 关闭其他占用相机或串口的程序，接好从臂、电源和双摄，把机械臂与物体摆到本次任务的起始位置。核对模型后点击“启动推理”。窗口显示加载与设备准备进度，准备完成后直接控制从臂，不需要到终端按回车。
6. 主窗口右侧上下排列两路大画面：上为桌面相机，下为夹爪相机；左下直接显示运行日志；勾选“显示关节状态”后，关节表在日志左侧展开，两者左右排列，可拖动分隔条调整宽度。画面成功显示后才允许启动运动。默认勾选“持续运行，直到点击停止”，此时秒数框禁用；取消勾选可使用初始 30 秒或自行填写的正数秒。点击“停止推理”、按 Esc 或关闭窗口会请求停止；窗口等待清理后退出，结束后保留最后一帧。

训练配置里原有的朋友电脑路径保持原样。程序只在内存里设置本机处理器位置，强制离线并严格加载权重，不需要运行模型包里的 `配置本机模型.py`。`training_provenance.json` 的原始来源与指纹也保留不变。

## 实机测试入口

实机窗口使用异步连续推理：后台预测，主线程按 20 Hz 检查输入和尝试发送动作，每块最多执行 20 步（最多覆盖 1 秒），新预测到达即替换并跳过过期步骤。2026-10-30 将执行窗口由 10 步调整为 20 步，以覆盖本机约 0.62 秒的推理周期，减少动作耗尽后的等待；模型计算耗时和单步限速保持原值。动作不足时保持最后目标，超时、画面中断、无效输出或电机故障会停止。实际发送频率受模型、相机和串口耗时影响。

任务模式相邻发送目标每步最多变化 0.5 个归一化单位，另有跟随误差检查；运行范围由对应演示、起始姿态及标定行程共同确定。任务推理不再受旧入口“3 秒、起点周围 3 单位、每块 1 步”的短程检查限制。身体关节和夹爪的归一化单位不是角度。加载成功与运行结束都不表示抓取成功，效果需现场观察。

夹爪单独按演示状态与动作的联合范围限制，不向任意起点或标定全行程扩展；起点在范围外时拒绝启用，不自动回位。本批训练夹爪起始状态约为 49.86～74.69；当前读数 100 超出训练状态范围，应先断电检查机械阻挡与标定，再按录制时开度摆好。启用扭矩前使用原始位置读写保持，避免归一化裁剪改变目标。

选择器会检查 SmolVLA 双摄输入（front、wrist）、六关节、演示 20 FPS、动作/状态关节顺序和训练记录。实际机械臂身份、标定、相机安装位置、画面内容和负载仍需现场核对。数据集参与活动范围计算，请选择与该模型及现场设置相符的演示。

## 终端指定路径

在项目终端、项目根目录运行以下示例。路径相对于当前项目，随项目迁移；也可给任意本机完整路径。启动器继续读取被 Git 忽略的 `运行环境/本机Python路径.txt`，共享代码不包含个人 Conda 安装路径。

```bat
脚本\离线实验\模型启动离线验证.bat --task-inference --model-dir "模型\双摄五位置_20261019_bs16_30000\best_val"

脚本\日常操作\启动模型推理.bat --model-dir "模型\双摄五位置_20261019_bs16_30000\best_val"
```

`启动模型推理.bat` 的参数用于预填窗口，不自动启动。离线验证指定 `--model-dir` 后不弹选择窗口；缺省数据集必须能从训练记录找到，否则报错，不会退回旧批次。处理器可通过 `--processor-dir "配套处理器完整目录"` 单独指定。

离线验证只使用录制画面和模拟关节，不打开串口或实时相机。`--task-inference` 检查与实机窗口相同的每块 20 步配置，模拟运行 4 秒；不加此参数保留历史每块 1 步检查。后者的连续性失败与任务配置报告需分开看。

需要旧短程检查时，可在项目终端运行 `脚本\日常操作\实机抓取测试.bat --model-dir "具体模型目录"`；该命令仍使用 3 秒/3 单位/每块 1 步并等待终端回车。日常观察任务效果请使用上面的推理窗口。

采集与训练面板的离线评估也会发现模型包中的多层模型目录；同名检查点按相对路径区分。其加载采用相同的本机处理器查找规则。历史“异步模型离线验证”与当前启动检查的模拟控制参数不同，报告不能互相替代。
