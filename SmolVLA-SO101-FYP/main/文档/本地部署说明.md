# 本地部署说明

当前主线为 LeRobot 0.3.4、SmolVLA、SO-101 主从臂和桌面/夹爪双摄，代码使用 [本项目 main](https://github.com/HDTHDT/SmolVLA-SO101-FYP)。项目目录和 Python 环境均不要求固定盘符。

## 当前验证环境与启动

2026-10-17 当前电脑实测 Python 3.10.20、LeRobot 0.3.4、PyTorch 2.7.1+cu126、torchvision 0.22.1+cu126、Transformers 4.51.3，RTX 4060 Laptop GPU 计算通过。其他包包括 NumPy 2.2.6、OpenCV 5.0.0.93、PyAV 17.1.0、PyArrow 24.0.0、pyserial 3.5、feetech-servo-sdk 1.0.0、imageio-ffmpeg 0.6.0、Pillow 12.2.0、ultralytics 8.4.96。这是当前电脑的检查记录，不是完整依赖锁定文件或其他系统的验证结果。

复用现有环境时，在项目根创建 `运行环境/本机Python路径.txt`，只写所选 `python.exe` 完整路径，UTF-8 无 BOM，不加引号。此文件被 Git 忽略。启动器依次使用 `LEROBOT_PYTHON`、本机路径文件、项目内虚拟环境、PATH 的 Python；训练面板子任务沿用同一个解释器。已有验证环境无需升级或复制整套 Anaconda。

双击 `脚本/环境配置/打开项目终端.bat`，在打开的终端运行：

```bat
python -m pip check
python "脚本/程序模块/检查本地环境.py"
python "脚本/程序模块/下载预训练模型.py"
```

缺模型先下载再复查。环境检查会枚举串口，不连接相机或驱动电机。`pip check` 检查包声明一致性；功能自检通过也不等于所有可选依赖都无冲突。启动、相机检查与录制步骤见 [启动指南](启动与采集操作指南.md)，模型来源和交接见 [项目文件来源与训练交接](项目文件来源与训练交接.md)。

## 新电脑安装

官方来源：[Python](https://www.python.org/downloads/)、[Anaconda（可选）](https://www.anaconda.com/download)、[PyTorch](https://pytorch.org/get-started/locally/)、[LeRobot 上游](https://github.com/huggingface/lerobot)。应安装本仓库的 `上游框架/`，不要直接用最新版 LeRobot 改变本批 v2.1 数据的接口。

仓库保留的较早 Windows 安装流程是：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "脚本/环境配置/安装本地环境.ps1"
```

它使用 Windows Python 启动器创建 **Python 3.12** 的 `运行环境/虚拟环境/`，读取 `文档/环境依赖.txt` 并安装 **PyTorch 2.7.1+cu128 / torchvision 0.22.1+cu128**。这是旧独立安装方案，与当前 Python 3.10/CUDA 12.6 环境不同；本次没有在空白机器重新验证，不要对现有 Conda 环境照搬执行。安装后应检查依赖、导入、CUDA、模拟录制和模型加载。无 GPU 可检查数据，当前训练/模型评估要求 CUDA。

OpenCV 图形预览需要 GUI 构建。上游依赖包含 headless 声明，安装时注意避免多个 OpenCV 包覆盖同一模块，检查实际 `cv2` 的 GUI 信息。

## 本机文件与设备

- 共享入口和源码：`脚本/`、`上游框架/src/lerobot/`（含必需的 `datasets/` 源码）。
- 环境、缓存、临时文件：`运行环境/`；每台机器自行配置，不上传。
- 官方与自训模型：`模型/`、兼容旧目录 `models/`；官网重下或单独传。
- 电机关节标定：`标定备份/`；与实际硬件配套另行备份。
- 运行日志：`运行记录/`、`run_logs/`；复现实验另传对应报告。
- 原始双摄数据：`../训练数据采集/机械臂控制项目/任务演示/`；完整批次另传。

默认主臂 USB 序列号 `5C82108314`，从臂 `5C82108242`，串口号可变；相机默认设备名 `1080P USB Camera` 与 `icspring camera`。迁移或换设备须核对角色、序列号、相机与标定，不能只改 COM 号。

只做离线训练无需连接硬件或加载本机标定。迁移自训模型需将其 `config.json` 中 `vlm_model_name` 改为部署机器的处理器目录；实际路径留在另传模型中，不写入共享源码。

当前录制两路保存 640×480、20 FPS。实机模型入口仍用早期短训练模型，默认最长 3 秒、每步变化不超过 1、相对起始姿态总行程不超过 3；完整模型启动离线验证尚未通过。详见 [启动指南](启动与采集操作指南.md) 和 [实机评测流程](实机评测流程.md)。
