新200段双摄红蓝任务训练（单卡RTX4090D）

数据：20261101_144759_857724，200段/93252帧/400个视频；RC100、BC100。
起点：随包本机官方基础SmolVLA权重；不继承旧100段训练的模型、统计或优化器。
任务文字、相机顺序front/wrist、RGB、512补边、动作块50与原部署一致。
固定batch16（红8蓝8）、BF16混合精度、可训练参数FP32、冻结视觉及VLM，训练专家和状态投影。
学习率1e-4，warmup500，余弦至2.5e-6；默认30K，每1K验证/保存last，每5K保存独立检查点。
训练160段（每色80）、验证40段（每色20）；仅训练段计算新归一化统计。
划分按颜色和录制顺序分层，不假定相邻段成对；没有布局标签，因此不能声称未见布局泛化。
best_val仅表示颜色均衡的留出动作MAE最低，不表示真实选色或抓取成功率。

AutoDL建议：基础镜像，Python3.10或3.11、PyTorch2.7.1、CUDA12.8、Ubuntu22.04。
驱动支持CUDA13.2并不要求安装CUDA13.2。社区镜像不能仅凭名称判断兼容。
镜像不存在完全相同组合时，选Python3.10/3.11基础镜像，运行安装依赖.sh。
不使用pip install -U lerobot，不用最新版官方训练入口替换包内程序。

将整个ZIP上传/root/autodl-tmp，用unzip解压。以下命令在解压目录运行：

bash 安装依赖.sh
source .venv/bin/activate
python 准备训练.py
# 先做2步保存/恢复试跑，仍用30K总学习率计划，结果输出到独立试跑目录：
python 启动训练.py --output 输出/试跑 --stop-after 2
python 启动训练.py --output 输出/试跑 --resume --stop-after 3
# 确认试跑无误再正式训练（建议在tmux内执行）：
python 启动训练.py

暂停：在另一个终端执行 touch 输出/新200段_batch16_30K/PAUSE
程序完成当前步后验证并保存last，再正常退出。不要在保存中强制关机。
恢复：确认已退出后执行 rm 输出/新200段_batch16_30K/PAUSE
然后：python 启动训练.py --resume
恢复要求保留同一解压位置、训练数据、源码和参数，包含优化器/调度器/随机数状态。
意外断电只能恢复最近完整last，尚未保存的步数可能丢失。
完整30K后不能直接修改--steps为60K并resume：学习率计划不同会拒绝混用。
如预先决定60K，须从头指定--steps 60000和新的output；其余弦计划不同于先30K再低学习率追加30K。

输出：输出/新200段_batch16_30K/best_val、last、step_005000等。
取回模型请下载整个检查点目录，不能只拿model.safetensors；部署选择本机处理器路径。
50GB盘可先用，完整检查点约2GB/份，需预留至少25GB给输出与保存临时副本；空间紧张时先扩容。

当前验证范围：见本地验证.json。未登录AutoDL，没有在4090D实际测时/训练。
硬件估时以试跑后稳定100～300步为准，不能仅按显卡型号保证4～5小时。
