# 机械臂项目操作说明

日常只需双击 [项目控制台.bat](项目控制台.bat)。打开控制台不会自动连接相机、机械臂或开始训练。

首次配置、双摄检查与录制见 [启动指南](../文档/启动与采集操作指南.md)；权重官网下载链接、单独发送的数据和模型目录见 [项目文件来源与训练交接](../文档/项目文件来源与训练交接.md)。本机 Python 路径只写入被忽略的 `运行环境/本机Python路径.txt`，不要修改共享入口中的路径。

## 常用操作

录制窗口只保留本段物体选择：RC 红方块、BC 蓝方块，任务指令自动生成。正常停止后自动预选另一种颜色；F7 保存后保持下一目标，F8 丢弃后恢复原目标重录；F5 开始、F6 停止。推理窗口仍可选择 RC/BC。旧四物体计划和标签读取保留兼容，历史说明见 [四物体采集说明](../文档/四物体单区与双区采集说明.md)。

| 操作 | 用途 |
|---|---|
| [采集与训练面板](日常操作/采集训练面板.bat) | 选择演示批次和模型，检查计划、训练与离线评估。 |
| [录制任务演示](日常操作/录制任务演示.bat) | 自行开始、停止和保存视频、动作与状态；录制包含主从同步。 |
| [相机预览](日常操作/相机测试.bat) | 自行开启桌面和夹爪双摄预览。 |
| [主从六关节同步](日常操作/同步测试.bat) | 会驱动从臂，操作终端按回车开始，最长 30 秒。 |
| [启动模型推理](日常操作/启动模型推理.bat) | 选择模型、点击启动，准备完成后控制从臂；默认持续运行直到停止；取消勾选后可设秒数；可随时停止。原模型抓取测试无参数双击也打开此窗口。 |
| [记录真实测试结果](日常操作/实机结果记录.bat) | 本人确认真实结果并绑定日志；不连接硬件。 |

## 目录怎么用

| 目录 | 内容 |
|---|---|
| `日常操作/` | 采集训练、录制、相机、同步、模型抓取、人工结果 |
| `离线实验/` | 数据检查、微调、动作评估、对比与模型验证 |
| `检查工具/` | 只读诊断、软件自检与实时只读推理 |
| `环境配置/` | 环境安装、环境变量、硬件端口和项目终端 |
| `程序模块/` | Python 实现与测试模块，一般无需逐个打开 |

[入口清单.json](入口清单.json)维护可见操作。新增单项入口放入对应分类，不在脚本根目录散放。Python 实现放入 `程序模块/`，固定第三方接口格式保留。

日常从项目控制台选择操作即可，不需要逐个运行 `程序模块/` 中的脚本。该目录仍保留控制台内部依赖、回归自检、模型下载，以及演示视频恢复、训练与实机分布分析、实验和日志汇总等专用工具；没有独立按钮不代表可以删除。已移除的旧诊断与一次性脚本见 [仓库清理说明](../文档/项目进展/仓库清理说明_20261019.md)。

## 推荐流程

1. 查看 [当前进展](../文档/项目进展/当前进展.md)，先做只读设备检查或相机预览。
2. 录制不同方块起始位置的演示，保存完整视频、状态、动作和任务。
3. 在采集训练面板选择训练批次，保留独立批次或完整演示段评估。
4. 离线验证通过后，按 [实机评测流程](../文档/实机评测流程.md)进行看护测试，人工记录结果。

当前双摄录制规格：桌面 640×480、夹爪 640×480，两路视频统一 20 FPS。重新打开录制窗口创建新批次，旧批次不改写。规格、模型图像链路及检查方法见 [双摄规格与采集说明](../文档/双摄规格与采集说明.md)；相机性能检查位于 `检查工具/双摄规格与帧率检查.bat`，应先关闭占用相机的窗口。

推理窗口右侧两路摄像头上下排列；勾选“显示关节状态”后，左下的关节表与日志左右排列，分隔条可拖动。模型推理窗口以“启动推理”按钮作为本次启动请求，无需终端回车；主从同步及显式命令行短程检查仍等待回车。推理保留每步限幅和故障检查，详见 [推理操作说明](../文档/自由选择模型与推理测试.md)。过载或停扭矩未确认时托住从臂并断电，不通过位置目标清除故障。

## 比较训练步数

在项目终端运行 `脚本\离线实验\比较训练步数.bat --help` 查看参数。指定 `--dataset-root`、已有基线 `--baseline-dir`、互不重叠的 `--train-episodes` 与 `--validation-episodes`。
`--steps 10000` 默认从固定基础模型重新训练 10,000 步，使用与基线一致的种子和 batch size，逐模型保存日志与评估报告。输出位于新的 `运行记录/步数对比_时间/`。

每个候选在相同留出段、相同采样位置上评估。按标准化动作误差选型，距最优 1% 以内优先较少步数；原模型保留，不自动更改实机入口。选型后这些留出段属于验证集，最终泛化与实机效果还需另批测试。

旧 51 段数据的 3000 步、10000 步模型已实测：只能大致对准物体，无法夹住并完成抓取。当时选出的 3000 步只是离线误差较低，不作为当前抓取推荐；当前成果使用五位置 50 段实验的 best_val。

## 本机保存位置

模型、环境、标定与原始日志留在本机。新演示保存在 `../训练数据采集/机械臂控制项目/任务演示/`（相对项目根目录），失败批次保留状态并归档。

淘汰的旧视觉方案、重复历史源码与历史兼容入口已移除；旧实现从 Git 历史追溯。早期迁移映射 [脚本整理报告](../文档/项目进展/脚本入口整理报告.json) 仅记录当时的路径，不代表当前入口。
# 目标选择时间标注入口

在项目控制台的“离线实验”页点击“标注目标选择视频”，或双击 `离线实验/标注目标选择视频.bat`。右上角“切换数据集…”可选目录，“输入数据集路径…”可粘贴根目录或相机视频文件夹路径。每段按1标记，自动保存并可直接导出，无需勾选或确认；选中标记按Delete删除。切换数据集时分别保留标记和进度，原200段标注兼容。只用于阶段采样，不生成错误指令惩罚。细则见 `文档/项目进展/目标选择视频标注使用说明.md`。只读视频，不启动训练或机械臂。

本次纯100段训练包的入口是“离线实验 → 检查百段阶段训练包”，或双击 `离线实验/检查百段阶段训练包.bat`。该入口只检查文件、标注及抽样，并显示B实验计划，不启动训练。上传及正式训练命令见 [纯100段AutoDL操作说明](../文档/项目进展/纯100段阶段采样AutoDL操作_20261107.md)。

语音指挥：重新打开模型推理窗口，点击“准备语音”后可用“说话并执行（5秒）”设置或切换RC/BC。未启动时只设置目标；运行中可随时单击切换，清空旧动作并丢弃旧推理，无需放置确认。详见 `../文档/语音指挥实机使用.md`。
