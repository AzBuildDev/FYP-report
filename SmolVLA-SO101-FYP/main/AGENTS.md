# 机械臂控制项目约定

- 自建运行、部署、测试和辅助脚本放在 `脚本/`，用中文命名并说明用途。
- LeRobot 源码位于 `上游框架/`，Git 历史位于项目根目录；Python 导入路径为 `上游框架/src`。
- Python 环境、缓存和临时文件分别位于 `运行环境/虚拟环境/`、`运行环境/缓存/`、`运行环境/临时文件/`。
- 模型、日志和标定分别放在 `模型/`、`运行记录/`、`标定备份/`。说明放在 `文档/`，已淘汰实现从 Git 历史追溯，不再保留重复源码树。
- 新演示保存在毕业设计项目 `训练数据采集/机械臂控制项目/任务演示/双相机演示_时间/`。保持视频、状态、动作、任务和元数据的对应关系。
- 固定的软件接口名和数据格式保留；普通自建资料用中文命名。
- 修改路径后验证入口、导入、模型加载与保存流程。目录整理不自动发出机械臂动作。
- Python 使用 UTF-8；中文批处理使用 `chcp 65001 >nul` 并给路径加引号。

- 脚本根目录仅保留项目控制台、入口清单和使用说明；单项入口按日常操作、离线实验、检查工具、环境配置分类。Python 实现和测试模块放在 `脚本/程序模块/`，项目根为其上两级。
- 新的可见操作加入 `脚本/入口清单.json`；保持内部中文模块的同目录导入，目录整理不启动真实硬件。
