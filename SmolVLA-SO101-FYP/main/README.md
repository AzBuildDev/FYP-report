## 答辩初稿资料（2026-11-09）

最新数据集区别、训练改动、暂停检查点和实机局限见[答辩资料索引](文档/答辩初稿资料索引_20261109.md)。完整训练/测试日志与现场截图见[实验归档](文档/实验归档_20261109/说明.md)，原始权重和视频数据集不纳入Git源码。以下较早阶段的成功描述有特定场景范围，不代表最新模型的统计成功率。

## 当前状态（2026-11-07）

当前推理窗口已接入百炼语音识别与语义理解：有效语音目标可直接使用当前所选模型启动推理；运行中切换 RC/BC 会清空旧动作队列。双摄日志分别记录故障。配置、操作和验收边界见 [语音指挥实机使用](文档/语音指挥实机使用.md)。

2026-10-30 录制界面简化：只选择本段目标 RC（红方块）或 BC（蓝方块），自动显示与推理一致的任务指令；正常停止后自动预选另一种颜色，F7 保存后保持下一目标，F8 丢弃后恢复原目标重录。快捷键为 F5 开始、F6 停止、F7 保存、F8 丢弃。旧四物体标签保持读取兼容，现有数据不改写。当前操作见 [启动与采集操作指南](文档/启动与采集操作指南.md)。

2026-10-24 软件更新：已新增 [四物体单区/双区采集支持](文档/四物体单区与双区采集说明.md)，包含规范任务、800 条空白计划、逐段标签和训练/开发约束。新任务尚未进行真实采集和模型验收；以下为原红方块模型的历史结果。
**历史红蓝30k语义对接：** 任务ID按本轮红/蓝训练文本映射，支持本地Qwen1.5B与Whisper tiny；安装、Release附件与离线dry-run见[红蓝语义任务对接](文档/红蓝语义任务对接.md)。自训SmolVLA和训练数据不包含在此次上传中，该离线语义流程未验证实机。

**操作者已现场确认：在训练演示中物体放置的五个大概起始位置，机械臂能够精准抓取红色方块，并放置到指定目标区域。**

- 五个位置之间的中间位置，以及超出五个位置覆盖范围的位置，仍会出现抓取不准，需要补充数据或继续微调。
- 放置时有概率压着目标区域的边界线放下，放置落点的一致性仍需改进。
- 本轮仅实测最新实验 `双摄五位置_20261019_bs16_30000` 的 `best_val`。实际权重 SHA-256 核对确认，它与 `last`、`step_030000` 完全相同，均为 30,000 步权重；其他 checkpoint 尚未逐个实测。
- 当前结果来自操作者现场观察，尚未汇总逐位置重复试验次数、成功率或数值精度。后续继续训练、比较数据与 checkpoint，找到实机表现最好的组合后再进一步研究。

当前模型对应 `双相机演示_20261019_100106_674366`，50 段演示，40 段训练、10 段验证；桌面 front、夹爪 wrist 两路视频为 640×480、20 FPS。**旧 51 段数据训练的 3,000 步和 10,000 步模型，操作者实测只能大致对准物体，无法夹住并完成抓取。** 旧模型与早期 3 段/50 步冒烟模型保留用于历史复现。

操作者怀疑早期演示数据质量不如当前五位置数据，这是待验证的原因假设；目前没有通过同条件对照实验确认，不能仅凭训练步数或离线误差归因。

## 环境要求

- Windows 10/11。
- Python 3.10 环境，安装项目所需的 CUDA 版 PyTorch、LeRobot 0.3.4、Transformers 及相机/串口依赖。
- 支持 CUDA 的 NVIDIA GPU；本项目当前在 RTX 4060 Laptop GPU 上验证。
- 两台 SO-101 和两路 USB 相机。串口号、相机索引和设备名应按实际机器修改或检查。

项目不写死盘符、用户名或 Conda 安装位置。启动脚本按以下顺序选择 Python：

1. 环境变量 `LEROBOT_PYTHON` 指向的解释器。
2. `运行环境/本机Python路径.txt` 第一行指定的解释器。
3. 仓库内 `运行环境/虚拟环境/Scripts/python.exe`。
4. 当前 `PATH` 中的 `python`，适合先激活 Conda/venv 后运行。

使用已有 Conda/venv 时，将该环境 `python.exe` 的完整路径写入 `运行环境/本机Python路径.txt`，使用 UTF-8 无 BOM 编码，只写一行且不加引号。之后可以直接双击中文入口，无须修改共享代码或永久修改系统 PATH。启动器同时配置 Conda 的 DLL 搜索路径；训练面板的子任务沿用启动面板的解释器。

`运行环境/` 已由 Git 忽略，本机解释器路径不会随普通提交上传；不要强制添加该目录。换电脑后重新创建本机配置，或使用 `LEROBOT_PYTHON` 临时覆盖。配置了无效路径时启动器会报错，不会悄悄换用其他 Python。依赖与实际启动检查见 [启动、双摄检查与录制指南](文档/启动与采集操作指南.md)。

PowerShell 示例：

```powershell
$env:LEROBOT_PYTHON = "D:\path\to\env\python.exe"
```

启动脚本设置 `PYTHONNOUSERSITE=1`，避免混入用户目录中的其他 Python 包。基础模型不会随 Git 仓库提供，固定模型仓库与 revision 记录在 [下载预训练模型.py](脚本/程序模块/下载预训练模型.py)。

## 推荐流程

1. 打开双摄预览，确认桌面视角同时覆盖起始区、机械臂和目标区，夹爪视角能看到接近与夹持过程。
2. 将目标区域固定在机械臂右侧，在左侧活动范围内改变红色方块起始位置。
3. 每条演示完整执行“接近、夹取、抬起、移动、放下、松爪、撤离”，失败演示不要混入训练集。
4. 先录 3 条并运行数据检查、短训练和离线推理，确认流程；目前该步骤已经通过。
5. 首轮可用约 50 条高质量演示训练；目标固定在右侧，覆盖前方/左前方的不同起点及方块角度。保留独立批次或完整段评估，根据失败分布再扩充数据。
6. 只有离线输出、时效、双摄输入和安全检查全部通过后，才进行有人看护的低速实机测试。

新演示保存在仓库同级目录：

```text
../训练数据采集/机械臂控制项目/任务演示/双相机演示_时间戳/
```

## 安全限制

- 双击推理入口只打开窗口；选好模型后，点击“启动推理”或识别到有效语音目标，加载及设备检查通过即开始运动，无需终端回车。
- 任务推理默认持续运行，直到点击停止；取消勾选后可输入正数秒（默认填入 30 秒）。任务模式限制相邻发送目标每步最多变化 0.5 个归一化单位，另有跟随误差检查，范围受演示、起始姿态和标定行程约束。
- 关闭监视窗口、按 `Esc` 或 `Ctrl+C` 会停止测试；退出时脚本尝试逐电机关闭扭矩并断开串口。
- 测试时必须有人看护并准备断电。模型预测超界、画面过期、黑帧、电机故障或标定不匹配时应拒绝启动或立即停止。
- 当前五位置成果对应上文指定任务模型；早期冒烟模型仅用于流程验证。
